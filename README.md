# Agenda de Horarios

Proyecto de practica de git.
# Como usar 
este proyecto es una agenda sencilla de practica. 
- README.md: explica el proyecto y su uso.
- contactos.txt: guarda nombres, teléfonos y correos.
- tareas.txt: contiene las tareas pendientes.
- compras.txt: contiene la lista de compras.
- .gitignore: indica qué archivos no debe guardar Git.
